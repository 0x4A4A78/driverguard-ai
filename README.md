# 🚗 DriverGuard AI: ระบบตรวจจับและแจ้งเตือนอาการหลับในอัจฉริยะ
> **Mini-Project วิชา AI (งานเดี่ยว)**

## 📌 1. ที่มาและความสำคัญ (Problem Statement)
อุบัติเหตุทางถนนจำนวนมากเกิดจาก **"การหลับใน (Microsleep)"** ซึ่งคนขับอาจหมดสติไปเพียง 1–3 วินาที แต่เพียงพอที่จะทำให้รถเสียหลักเกิดอุบัติเหตุร้ายแรงได้ โครงงานนี้จึงพัฒนาเว็บแอปพลิเคชันต้นทุนต่ำ (Low-cost) ที่สามารถทำงานบนสมาร์ตโฟนหรือคอมพิวเตอร์ทั่วไปได้ทันที โดยไม่ต้องติดตั้งเซนเซอร์ฮาร์ดแวร์เพิ่มเติม อาศัยเพียงกล้องหน้าและสมองกล AI ในการวิเคราะห์พฤติกรรมผู้ขับขี่แบบเรียลไทม์

### 📐 สูตรคำนวณทางคณิตศาสตร์

#### 1. Eye Aspect Ratio (EAR)
อ้างอิงจากงานวิจัยของ *Tereza Soukupová และ Jan Čech (2016)* ใช้จุดพิกัด 6 จุดรอบดวงตา:
$$EAR = \frac{||p_2 - p_6|| + ||p_3 - p_5||}{2 \times ||p_1 - p_4||}$$

* **สภาวะลืมตาปกติ:** ค่า EAR จะอยู่ที่ประมาณ $0.25 - 0.35$
* **สภาวะหลับตา:** ค่า EAR จะลดลงต่ำกว่า $0.20$
* **การตัดสินใจ (State Logic):**
  * ถ้า $EAR < 0.22$ เป็นเวลา $0.1 - 0.45$ วินาที $\rightarrow$ นับเป็นการ **"กะพริบตาปกติ (Blink)"**
  * ถ้า $EAR < 0.22$ ค้างเกิน **1.5 วินาที** $\rightarrow$ ส่งสัญญาณเตือน **"หลับใน (Microsleep Alert)"**

#### 2. Mouth Aspect Ratio (MAR)
ใช้ประเมินอาการหาว (Yawning) จากอัตราส่วนความกว้างและสูงของช่องปาก:
$$MAR = \frac{||p_{top\_inner} - p_{bottom\_inner}||}{||p_{corner\_left} - p_{corner\_right}||}$$
* ถ้า $MAR > 0.62$ ติดต่อกันเกิน $1.8$ วินาที $\rightarrow$ เตือนว่าผู้ขับขี่เริ่มมีอาการเหนื่อยล้าสะสม

## ✨ 3. ฟีเจอร์เด่นของระบบ

1. **ประมวลผลบน Client-Side 100% (Edge AI ในเบราว์เซอร์):**
   * รันโมเดล AI ผ่าน WebAssembly/WebGL โดยตรงบนเครื่องผู้ใช้ ภาพจากกล้องไม่ถูกส่งไปยัง Server ปลอดภัยต่อความเป็นส่วนตัว (Privacy-first) และทำงานลื่นไหล 30+ FPS
2. **ระบบเตือนภัย 2 ชั้น (Dual-layer Audio Alert):**
   * **ชั้นที่ 1 (Siren Synthesizer):** สร้างสัญญาณเสียงไซเรนฉุกเฉินความถี่สูง (880Hz / 1320Hz) ผ่าน Web Audio API ไม่ต้องดาวน์โหลดไฟล์เสียง mp3
   * **ชั้นที่ 2 (Thai Speech Synthesis):** เสียงพากย์ภาษาไทยเตือนสติ *"อันตราย! ตรวจพบอาการหลับใน กรุณาตื่นค่ะ"*
3. **หน้าจอ HUD กึ่งโปร่งใส (Automotive Cockpit HUD):**
   * วาดมาร์กเกอร์และกรอบเล็งใบหน้าแบบ AR
   * แสดงกราฟคลื่นการกะพริบตา (Rolling Waveform Chart) สดๆ เมื่อหลับตาเส้นกราฟจะดิ่งลงต่ำกว่าเกณฑ์ทันที
4. **โหมดนำเสนอ & สแกนทดลอง (Audience Interactive QR Mode):**
   * มีปุ่มเปิด QR Code หน้าห้องเรียน ให้อาจารย์และเพื่อนๆ สแกนเปิดเล่นบนมือถือของตัวเองได้ทันที
5. **ปุ่มจำลองเหตุการณ์ (Simulate Alarm):**
   * มีปุ่มทดสอบส่งเสียงเตือนทันที 3 วินาที สำหรับใช้เดโมรวดเร็วโดยไม่ต้องหลับตาจริง

## 🚀 4. วิธีเปิดใช้งานและรันในเครื่อง (Quick Start)

### ความต้องการของระบบ
* Node.js (เวอร์ชัน 18 ขึ้นไป)
* กล้องเว็บแคม (หรือกล้องสมาร์ตโฟน)

### ขั้นตอนการรัน
```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd /Users/mac/Sau/3-1/ai/drowsiness-ai

# 2. ติดตั้ง Dependencies (ทำครั้งแรกครั้งเดียว)
npm install

# 3. รันเซิร์ฟเวอร์สำหรับทดสอบในเครื่องคอมพิวเตอร์
npm run dev
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:5173`

## 📱 5. วิธีเปิดบนมือถือ (ให้เพื่อน/อาจารย์สแกนเล่นหน้าห้อง)

### ทางเลือกที่ 1: Deploy ขึ้น Vercel (แนะนำที่สุด ⭐ ง่าย ฟรี ได้ลิงก์ HTTPS ถาวร)
เนื่องจากกล้องบนมือถือจำเป็นต้องใช้ **HTTPS** การขึ้น Vercel จะได้โดเมน HTTPS ทันที:
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub
2. เข้าเว็บ [vercel.com](https://vercel.com) แล้วกด **Add New Project** $\rightarrow$ เลือก Repo นี้
3. กด **Deploy** (ใช้เวลา 1 นาที) จะได้ลิงก์ เช่น `https://driverguard-ai.vercel.app`
4. นำลิงก์นี้ไปเปิดในโปรแกรม หรือพิมพ์ใส่ช่องในโปรแกรมเพื่อสร้าง QR Code ฉายขึ้นโปรเจกเตอร์หน้าห้องได้เลยครับ!

### ทางเลือกที่ 2: รันผ่าน Wi-Fi เดียวกันด้วยคำสั่ง HTTPS
```bash
npm run dev:https
```
คำสั่งนี้จะเปิดเซิร์ฟเวอร์แบบ HTTPS และแสดง IP เครื่องของคุณ เช่น `https://192.168.1.150:5173` ให้อุปกรณ์ที่ต่อ Wi-Fi เดียวกันเปิดได้
