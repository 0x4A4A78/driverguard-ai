SECTION 03 // ALGORITHM & BIOMETRIC GEOMETRY

สูตรคณิตศาสตร์ Eye Aspect Ratio (EAR) & เครื่องจำลองสด

SOUKUPOVÁ & ČECH (2016)
Mathematical Foundation

การคำนวณสัดส่วนความกว้างต่อความสูงเปลือกตา

EAR = (||p₂ - p₆|| + ||p₃ - p₅||) / (2 × ||p₁ - p₄||)
p₁, p₄: หัวตา & หางตา (แนวนอน)
p₂/p₆, p₃/p₅: เปลือกตาบน-ล่าง
• EAR ≥ 0.26: สภาวะตื่นตัวปกติ (Normal Awake)
• 0.22 ≤ EAR < 0.26: เริ่มมีอาการเหนื่อยล้า (Drowsiness Warning)
• EAR < 0.22 (≥ 1.5 วินาที): ยืนยันหลับใน (Microsleep Alarm)
Temporal Filter: การกะพริบตาธรรมชาติใช้เวลาเพียง 100–300ms ระบบจึงไม่ส่งสัญญาณเตือนหลอกจากการกะพริบตาทั่วไป
LIVE TELEMETRY & EYE VECTOR SIMULATOR NORMAL AWAKE
EAR TIME-SERIES WAVEFORM THRESHOLD: 0.22
ปรับระดับการเปิดตา (EAR): 0.30

METRIC 01 // LIGHTWEIGHT FOOTPRINT
ขนาดสคริปต์รวมเพียง 46 kB (Gzip 14 kB)

ตัด Library ภายนอกที่ไม่จำเป็นออกทั้งหมด เขียนอัลกอริทึมเรขาคณิตเวกเตอร์ด้วย Vanilla JavaScript โหลดหน้าเว็บและเริ่มวิเคราะห์ภาพได้ภายใน 400 มิลลิวินาที แม้ใช้งานบนเครือข่ายมือถือ 4G ทั่วไป

METRIC 02 // ZERO-DEPENDENCY AUDIO
Web Audio API Oscillator ไร้ไฟล์เสียง MP3

ใช้คลื่นเสียงสังเคราะห์รูปฟันเลื่อย (Sawtooth Wave) สลับความถี่ 880Hz และ 1320Hz สดในชิปเสียงของอุปกรณ์ แก้ปัญหาไฟล์ MP3 โหลดไม่ทัน เสียงดีเลย์ หรือเปิดไม่ติดบนเบราว์เซอร์ 100%

METRIC 03 // DUAL-ALERT SPEECH
ผสานระบบสั่งการเสียงพูดเตือนสติภาษาไทย

ใช้ Web Speech Synthesis (`SpeechSynthesisUtterance`) ส่งเสียงสั่งการเตือนสติเป็นระยะ ร่วมกับ Emergency Strobe Overlay สีแดงกระพริบทั่วหน้าจอเพื่อกระตุ้นประสาทตาของผู้ขับขี่

METRIC 04 // MULTI-MODAL DETECTION
Mouth Aspect Ratio (MAR) & Head Slump

ไม่เพียงตรวจจับการปิดเปลือกตา แต่ตรวจวัดพฤติกรรมการหาวต่อเนื่อง (MAR > 0.65) และมุมการก้มคอสัปหงก (Head Pitch) ประเมินคะแนนความตื่นตัว (Driver Alertness Score 0–100%)
